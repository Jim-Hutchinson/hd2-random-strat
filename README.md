## 🚀 Run It Locally

No build step, no install — see [LOCAL-SETUP.md](LOCAL-SETUP.md).

- Double-click `randomizer/index.html`, or
- run `start-randomizer.bat` (Windows) / `./start-randomizer.sh` (macOS/Linux)
  to start a tiny local server and open the randomizer automatically.
